# Decant Builder

## Vision

Interactive fragrance discovery box builder that helps users create a balanced fragrance collection through a points-based system.

---

## Current Features

### Catalog

* Tier system

  * Bronze = 1 pt
  * Gold = 2 pt
  * Platinum = 2.5 pt
  * Diamond = 4.5 pt
  * Mythic = 6 pt

* Perfume cards

* Notes display

* Best-for display

* Tags and accords

### Box Builder

* Add/remove fragrances
* Points tracking
* Value tracking
* Upgrade value tracking
* Discovery Box requirements

### Analysis Engine

* Coverage analysis
* Strength detection
* Seasonal gap detection
* Seasonal recommendations
* Recommended picks

### Profile Generation

* Occasions profile
* Seasons profile
* Vibes profile
* Scent palette profile
